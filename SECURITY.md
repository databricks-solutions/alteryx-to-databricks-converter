# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly. **Do not** open a public GitHub issue for security problems.

Instead, email **bugbounty@databricks.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce (proof-of-concept if available)
- The affected version or commit

You will receive an acknowledgement of your report. Please allow time for the
issue to be investigated and resolved before any public disclosure.

## Supported Versions

This project is provided as-is. Security fixes are applied on a best-effort
basis to the latest release on the `main` branch. Older versions are not
maintained.

## Scope

This is a Databricks field-engineering asset, not an officially supported
Databricks product. See [the project disclaimer](README.md) for support
expectations.
